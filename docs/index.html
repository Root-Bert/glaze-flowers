Glaze Flowers

Happy flower avatars in the look of a hand-painted, glazed ceramic vase. One seed, one flower. Free to use, no credit needed (CC0). GitHub

Use

npm install glaze-flowers

import { createFlower } from 'glaze-flowers';
const svg = createFlower({ seed: 'Robert', background: 'auto', radius: 50 });
